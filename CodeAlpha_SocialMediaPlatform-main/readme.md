# Social Media Platform

A simple social media platform that allows users to register, log in, create posts, like posts, comment on posts, and follow other users.

## Features

- User Registration and Login
- Create and View Posts
- Like Posts
- Comment on Posts
- View All Users
- Follow and Unfollow Users
- User Profiles
- Display Total Posts

## Technologies Used

**Frontend:**
- HTML
- CSS
- JavaScript

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB
- Mongoose


## Installation and Setup

### Prerequisites

- Node.js and npm installed
- MongoDB connection configured

### Backend Setup

Open the terminal and navigate to the backend folder:

```bash
cd backend
```

Install dependencies:

```bash
npm install
```

Start the backend server:

```bash
node server.js
```

The backend server will run at:

```text
http://localhost:3000
```

### Frontend Setup

1. Open the `frontend` folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click and select **Open with Live Server**.

The frontend will open in your default browser.

## Database Configuration

Configure your MongoDB connection in the backend database configuration file (`db.js`) before starting the server.

## Usage

1. Register a new account.
2. Log in using your credentials.
3. Create and share posts.
4. Like and comment on posts.
5. Explore other users.
6. Follow or unfollow users.
7. View user profiles and their posts.
